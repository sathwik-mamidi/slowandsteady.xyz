# Contributing

Thanks for helping improve Slow and Steady.

1. Fork the repository and create a focused branch.
2. Install dependencies with `npm install`.
3. Make the change and add or update tests where practical.
4. Run `npm test` and `npm audit --omit=dev`.
5. Open a pull request that explains the behavior change and how it was tested.

Do not commit `.env` files, Redis snapshots, server backups, credentials,
private keys, or real player data. Keep pull requests small enough to review and
use clear commit messages without automated co-author trailers.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a
public issue.
